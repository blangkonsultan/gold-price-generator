# Actual browser OCR verification

Target: the real source modules, self-hosted Tesseract.js 7 worker/core/model, and the owner's supplied JPEG copied to `tests/fixtures/reference-price-list.jpg`. This is pipeline evidence before the production UI is connected, not a claim that the app interface is finished.

## Executed path

1. Started the registered loopback Vite server on port 5174; its predev hook prepared ten pinned local OCR assets.
2. Opened the owned, ignored `.superpowers/smoke/ocr.html` page in Chromium.
3. Selected the real fixture through its native file input; `decodeUpload` decoded 1024 × 1280, not a fabricated canvas or sample-price dictionary.
4. Ran actual worker recognition over all eleven price regions and the date, with preprocessing on separate crop canvases.
5. Compared the results below against the prices visible in the original photo.

## Startup cancellation and failure behavior

- Canceled the real reader while its core was still loading. The promise rejected with `AbortError`; the instrumented native worker count returned to zero.
- Selected the same real JPEG again; all prices/date above were recognized and the worker count returned to zero after success.
- Temporarily renamed the owned generated traineddata file, selected the JPEG again, and observed the real HTTP 404 from the worker's model fetch. The reader rejected with the model failure rather than hanging; active workers returned to zero. The generated model was restored in a `finally` block.
- This used actual workers, not a mocked Tesseract API. The temporary page observed worker messages solely for verification and is not part of the application bundle.

## Network scope

Observed successful/cached requests used the loopback origin for `/ocr/worker.min.js`, `/ocr/core/tesseract-core-relaxedsimd-lstm.wasm.js`, and `/ocr/lang/eng.traineddata.gz`. No remote OCR service was involved. The expected canceled core fetch showed `ERR_ABORTED`; the deliberately removed model showed 404. The temporary page also lacked a favicon; production page metadata is still to be implemented.

## Supporting checks and remaining work

Pure regressions cover OCR ambiguity/unsafe values, source-session clearing and stale callbacks, confirmation invalidation, invalid raster headers, and calendar boundaries. The Native task ledger records their actual completion command/results.

Still required: native-resolution renderer/PNG proof, complete editing UI, source correction and markup interaction, mobile audit/polish, production build, independent release review, GitHub push, and Vercel preview. The temporary smoke page must be removed after the real integrated path is exercised.

## Failure recovery confirmation

After restoring the generated model, a fresh selection in the same browser page again recognized all eleven prices and `2026-09-30`. The browser's native `page.workers()` inventory was empty after completion, independently of the temporary constructor/terminate counter. The captured HTTP request list contained no remote-origin requests; the restored language-model fetch returned 200. Expected cancellation and the deliberately induced 404 are recorded as negative-path evidence, not hidden as normal successes.
